Running a sweep

Sweeps run from the command line, not from this page. The agent is non-deterministic — cases have behaved differently on identical input — so a single run is close to noise. The runner measures a pass rate over many runs and writes the result into the repository, where it is versioned and can be read by someone other than the person who ran it.

export ANTHROPIC_API_KEY=...
node test/eval-runner.js --runs 20          # a normal sweep
node test/eval-runner.js --runs 100         # before a release
node test/engine-test.js index.html         # arithmetic only, no key
